# Sparse Road Network Using Linked Lists

## 📌 Project Overview

The Sparse Road Network project demonstrates how a road network can be represented using sparse data structures.

A road network consists of locations connected by roads. Since each location usually connects to only a few other locations, sparse representations can help reduce unnecessary storage.

This project includes a C implementation and an interactive web visualizer.

## 🎯 Objectives

- Understand sparse matrix representation.
- Represent a road network using linked lists.
- Explore Coordinate (COO) representation.
- Understand memory efficiency in sparse data structures.
- Visualize the structure and connections of a road network.

## ✨ Features

- Sparse road network representation.
- Sparse adjacency matrix representation.
- Coordinate (COO) representation, where implemented.
- Linked list representation.
- Interactive visualization of road network connections.

## 🚀 How to Run the C Program

Make sure GCC is installed on your system.

1. Clone or download this repository.
2. Open a terminal in the folder containing the C file.
3. Compile the program:

   ```bash
   gcc sparse_road_network.c -o sparse_road_network
   ```

4. Run the compiled program.

   **Windows:**
   ```bash
   sparse_road_network.exe
   ```

   **Linux/macOS:**
   ```bash
   ./sparse_road_network
   ```
